Search interest dataset

Google Trends interest (0–100) for nine health conditions in every metro area and year — after the corrections described on the overview page. Filter by state or year, sort any column, and export what you see. Scores compare places within one condition and year; see how to read them.

CDC leading causes of death

US age-adjusted death rates per 100,000 people. The 2017 cancer value was corrected from 52.5 to 152.5.

Data files (former API endpoints)

Each endpoint of the original Flask API is now a static JSON file in the same format ({"schema", "data"}), so it is always available. The original PostgreSQL source CSVs are in the repository.

  • Sum of scores by yearsearchbyyear.json
  • Sum of scores by year and conditionsearchyearandcondition.json
  • Sum of scores by statesearchbystate.json
  • Sum of scores by metro areasearchbycity.json
  • Scores by state and yearbystateandyear.json
  • CDC leading causes of deathcasesleadingdeath.json
  • All records (metro × year)allsearchrecord.json
  • Metro areas & coordinateslocation.json
  • Search conditions tableconditions.json
  • Top ten states by conditionmostsserached.json
  • Sum by conditiontotalcondition.json
  • Sum of CDC death ratestotaldeathcase.json
Note: the "sum" files add up 0–100 scores as the original API did. Because every condition and year is scaled separately, those totals shouldn't be compared across conditions or years.
